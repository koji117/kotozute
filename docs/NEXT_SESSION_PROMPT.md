# ローカルの新しいセッションに渡すプロンプト

## 準備

1. 受け取った `kotozute.zip` を、iCloud で同期されないフォルダ（例：`~/dev`）に展開する。数GBのデータをリポジトリの直下に置くので、「書類」や「デスクトップ」は避ける。
2. そのフォルダで `claude` を起動し、下の文をそのまま貼り付ける。

```bash
cd ~/dev/kotozute && claude
```

---

このリポジトリは、ハッカソン「Built with Claude: Japan 2026」に1人で出す「ことづて」（AIで動くOSMビューア）です。クラウドのセッションで調査・計画・絵コンテ動画まで終えたので、ここから実装を始めます。締切は11月8日（日）20:00 JSTです。

まず CLAUDE.md、docs/HANDOFF.md、docs/plan.md を読んでください。細かい技術の注意点は private/plan-critique.md にあります（private/ は Git に入れない手元だけのメモです）。

進め方のお願い：
- 曖昧なところや決まっていないことは、勝手に補完せずに質問してください。
- 事実・推測・未確認を区別してください。
- 社名、社内の情報、同僚の実データ、勤め先の業種が分かる記述は、どこにも入れないでください。公開データだけを使います。リポジトリは将来公開するので、迷うものはコミットする前に聞いてください。
- 言語やフレームワークなどの技術選定は、案を出して私に確認してから進めてください。新しいソフトを入れるときは、何を入れるか先に教えてください。

今日（11/4）のゴールは【M0】です：日本語の入力 → Claude → 住所検索 → 地図が動き、操作ログが1行出る。

最初にやってほしいこと：
1. 開発環境を確認する（Apple Silicon の Mac Studio、96GB）。Docker Desktop とそれに割り当てたメモリ・ディスク、Node、osmium、pmtiles、ffmpeg、git、gh の有無を調べ、足りないものを一覧にして、入れる前に私に確認する。あわせて、Claude API のキーがあるか（サーバ側で環境変数 ANTHROPIC_API_KEY として .env から読む。キーの中身は表示もコミットもしない）と、M0 のツールループに使うモデルを私に確認する。
2. docs/HANDOFF.md の「今日の手順」1〜5（データの取得、Overpass、Valhalla、Protomaps の地図ファイルとフォント、住所ジオコーダー）をバックグラウンドで走らせる。手順はまだ誰も実行していないので、つまずいたら原因を調べてから報告する。
3. 待つ間に、Webアプリの構成案（言語、フレームワーク、ディレクトリ構成、型付き操作の定義の置き場所）を出して、私の確認を取る。
4. 確認が取れたら、MapLibre と自前の PMTiles で地図を出す骨格と、CLAUDE.md の「Claude Code の使い方」に書いた hook（.claude/settings.json）を作る。

docs/HANDOFF.md の「ユーザーへの確認事項」は、答えが必要になった時点で私に聞いてください。
