日本ファースト

住所（丁目・番・号）、駅の名前、平面直角座標、地域メッシュ、度分秒に、追加の設定なしで
日本の地図は、むずかしい

住所の書き方

  • 港区芝公園4-2-8
  • 港区芝公園四丁目2番8号
  • 港区芝公園４－２－８
  • 港区芝公園4丁目2-8
  • → どれも同じ街区（芝公園4丁目2）

駅の名前

  • 「品川駅」と頼んでも
  • OSM の駅の名前は「品川」
  • → 駅としても探す

座標

  • 平面直角座標は19の系（東京は9系）
  • 地域メッシュ（例：53394611）
  • 度分秒（例：北緯35°40′52.4″）
住所は、2026年11月7日に手元の住所のデータ（アドレス・ベース・レジストリ）で試した結果。座標の計算は国土地理院の式（平面直角座標）と JIS X 0410（地域メッシュ）
