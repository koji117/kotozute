# デモ用のデータ

## ward-offices.csv（23区の区役所）

MCP の一括処理の場面（`docs/mcp.md`）で使う。東京23区の区役所（本庁舎）の区・名称・住所の23行。

- 出典：OpenStreetMap（© OpenStreetMap contributors、ODbL 1.0。https://www.openstreetmap.org/copyright ）。このCSVは OSM のデータを含むので ODbL 1.0 で扱う。
- データ時点：OSM 2026-11-03T21:24:04Z（手元の Overpass の `timestamp_osm_base`。関東のデータ）。
- OSM に住所のタグがない区などは、区の公式サイトのトップページにある本庁舎の所在地を使った（2026-11-05 に確認）。下の表の「住所の出どころ」に区ごとに書いた。
- 作り方：`npx tsx scripts/build-ward-offices.ts`（手元の Overpass :12345、ABR :3002 を使う）。

### 確かめたこと

すべての行について、次の2つを確かめてから書いた（どちらかが外れたらスクリプトが止まる）。

1. 手元の ABR（デジタル庁のアドレス・ベース・レジストリ）で、住所が街区以上まで一致する。
2. ABR の点が、OSM の区役所の位置から 200m 以内にある。

住所の書き方（「一丁目」「1丁目」「13番14号」など）は、出どころの書き方のまま。ABR がそろえる。

### OSM の住所を使わなかった区と、その理由

| 区 | OSM の状態 | どうしたか |
|---|---|---|
| 千代田、文京、墨田、品川、大田、中野、杉並 | 区役所の要素に住所のタグがない（郵便番号だけ、または何もない） | 区の公式サイトの所在地。郵便番号のタグがある6区（千代田、文京、墨田、品川、大田、杉並）は、公式サイトの郵便番号と一致した |
| 渋谷 | `addr:quarter=宇田川町`、`addr:neighbourhood=１丁目`。宇田川町に丁目はなく、ABR は「渋谷区」までしか一致しない | 区の公式サイトの所在地 |
| 豊島 | 住所のタグが旧庁舎の住所（東池袋一丁目18-1）のまま。ABR の点が OSM の位置から 695m | 区の公式サイトの所在地（サイトの表記には「東京都」がないので前に足した） |

### 区役所の要素とは別の OSM の要素から住所を取った区

| 区 | どうしたか |
|---|---|
| 中央 | 区役所の要素は郵便番号だけ。同じ場所の node/1655903235 の `addr:full`「東京都中央区築地1-1-1中央区役所4階」から、階と館名を落とした |
| 荒川 | 区役所の要素（node/2010120271）は郵便番号だけ。同じ名前「荒川区役所」の建物 way/237515679 の住所タグを使った |
| 練馬 | `amenity=townhall` で「練馬区役所」という要素がない。同じ名前の建物（`building=government`）way/27384338 の位置と住所タグを使った |
