地図のデータ

ことづては、地図・検索・ルート・住所のデータを、この Mac の中に作って使います。はじめに一度、次のデータをダウンロードして、東京のデータを作ります。

OSM のデータ（関東）約 500MBGeofabrik
download.geofabrik.de
地図の絵約 190MBProtomaps
build.protomaps.com
住所のデータ（東京）、ルートの速度表約 22MBGitHub
github.com、release-assets.githubusercontent.com、raw.githubusercontent.com

この Mac に要るもの

空きディスク：作るあいだ約 5GB。作ったあとに残るのは約 1.6GB です。

メモリ：作るあいだ最大で約 4GB を使います。

時間：数分から十数分（ネットの速さと、この Mac によります。開発した Mac Studio では約4分でした）。

通信について

このアプリが上の場所と通信するのは、「ダウンロードして作る」と「最新にする」を押したときだけです。地図を使っているあいだに外に出るのは、日本語の依頼を読む Claude API だけです。

途中で止めても、OSM のデータ（約 500MB）は次に続きから取ります。

「最新にする」を押すと、OSM（Geofabrik）と地図（Protomaps）の最新のデータと住所のデータ（GitHub）を取って、作り直します。ダウンロードは約 700MB、時間は数分から十数分です。

作るあいだも、今のデータで地図を使えます。この画面を閉じても作り続けます。できたら新しいデータに切り替えて、地図の画面を読み直します。うまくいかなければ、今のデータのままです。
