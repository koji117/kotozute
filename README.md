# ことづて（kotozute）

**その地図、明日も使えますか？**

言葉を託すと、渡せる地図が返ってきます。ことづては、日本語のひとことで頼める OpenStreetMap（OSM）の地図アプリです。地図・検索・ルート・住所は、手元のマシン（自分の PC か社内のサーバ）で動きます。

- **試す**：Mac のアプリ（.dmg）を入れて、ご自分の Claude API のキーで使います（下の「[試す](#試す)」）。範囲は東京都（島しょ部を除く）です
- **デモ動画（3分）**：YouTube に上げたあと、ここに URL を入れます
- **応募**：「Built with Claude: Japan 2026」テーマ1「あなたにしかない深さを」

このリポジトリは、ハッカソンの期間中に作りました。作業は 11/2 のキックオフのあとに始めました。11/4 の最初のコミット（c6080e5）までは、計画・調査・絵コンテを作っていました。地図の表示（MapLibre）、ルートの計算（Valhalla）、住所の照合（abr-geocoder）、地図のデータ（OSM、Protomaps）は、既存の OSS と公開データを部品として使っています。作ったものと使ったものの一覧は、下の「[期間中に作ったもの](#期間中に作ったもの)」と「[使ったOSS・公開データ](#使ったoss公開データ)」にあります。出典は「[出典の表示](#出典の表示)」、ライセンスは「[ライセンス](#ライセンス)」にあります。

この README の前半（「デモの流れ」まで）は、デモ動画と同じ順です。Claude の使い方は「[アプリの中での Claude の使い方](#アプリの中での-claude-の使い方)」と「[Claude Code の使い方](#claude-code-の使い方)」にあります。

## その地図、明日も使えますか？

あなたの組織では、Google マップなどの地図アプリを無料で使っていませんか。

業務で地図を使う人は、地図の専門家だけではありません。客先へのルートを相手に送る。資料に地図を貼る。こうした仕事に、無料の地図アプリを使っている職場があります。

無料で使っていても、地図会社と SLA（稼働率などサービスの品質を約束する契約）を結んでいるわけではありません。業務で使ってよい範囲は、Google のガイドライン（Geo Guidelines）に例で書かれているだけです。規約を決めるのも、変えるのも地図会社です。変更によっては、明日、業務が止まるかもしれません。変更は、地図アプリを使う人にも、地図を組み込んだ業務のシステムにも及びます。

これまでも、規約の変更、有料化、値上げ、サービスの終了が、何度もありました。

- **2011年10月**：Google Maps API。一定の量を超える利用を有料にする方針が発表されました（INTERNET Watch 2011年10月・11月）。これは方針の発表です。請求の対象は、上限を90日続けて超えたサイトだけとされました。
- **2018年6〜7月**：Google Maps Platform。6月に API キーと支払いの設定が必須になり、キーのない一部のサイトでは地図が灰色になりました。7月からは、Maps JavaScript API の無料の範囲が、1日 25,000回から月 約28,000回になりました（INTERNET Watch）。無料の枠を超えた分の料金は、1,000回あたり 0.5ドルから 7ドルになりました（GIGAZINE 2018年7月、I Programmer 2018年7月）。
- **2019年3月**：日本の Google マップの地図が作り替えられました。道やバス停が欠けたと報道されました（週刊アスキー）。欠けた理由は、Google は説明していません。
- **2020年12月**：Mapbox GL JS。v2.0.0 から3条項 BSD ライセンスをやめ、使うには Mapbox の利用規約への同意が要るようになりました（v2.0.0 のリリースノート）。
- **2024年**：Microsoft は Bing Maps for Enterprise の提供の終了を発表しました。無料のアカウントは 2025年6月30日まで、有料のアカウントは 2028年6月30日までです（Microsoft Learn）。
- **2026年7月**：Google Earth Pro のデスクトップ版は、新しいダウンロードを 2027年6月25日で終えると発表されました（窓の杜）。Google Earth の画像は、今も商用や宣伝には使えません（Geo Guidelines）。

出典と確かめた日は `docs/research/google-map-changes.md` と `docs/research/other-map-changes.md` にあります（調査のメモは英語の部分があります）。

## 作った人の考え

地図は誰もが日常的に使う道具です。生活の基盤だからこそ、一企業の都合に左右されず、自由に使える人類の共通アセットであるべきだと思います。

## 足りないもの

無料で使えるオープンな地図もあります。OpenStreetMap（OSM）は、誰でも使えるオープンデータ（ODbL）です。データを手元に置き、自分のマシンで動かせます。どこか1社の判断で止まりません。

しかし、使うのには専門知識が要ります。手元で動かす OSM で「港区の郵便局」を探すと、こう書きます。

```
[out:json][timeout:25];
area["name"="港区"]->.a;
nwr["amenity"="post_office"](area.a);
out center;
```

書けても、落とし穴があります。

- OSM の「郵便局」のタグ（`amenity=post_office`）には、宅配便の営業所も混じります（関東で約80件。`src/ops/dict.ts`）。
- JR の品川駅の OSM の名前は「品川」です。「品川駅」で探すと、同じ名前のバス停が当たります。
- 住所の書き方はいろいろあります（「4-2-8」「四丁目2番8号」「４－２－８」）。

地図業界で長く働いてきた作者が、ずっと足りないと思っていたのは、「Google マップや地図ベンダーに頼らず、地図に詳しくなくても使える地図アプリ」です。ことづては、それを作る試みです。OSM の落とし穴は、辞書とプログラムが引き受けます。使う人は、日本語で頼むだけです。

## 3つの約束

| 約束 | 中身 |
|---|---|
| ① 言葉から地図へ。ひとことで頼むと、数秒で地図ができる | 作りたい地図を、言葉で伝えるだけです。難しい設定や専門知識は要りません。検索文も OSM のタグも知らなくてよいです。インストールも簡単です |
| ② ローカルファースト。外部に依存しない | 地図、検索、ルート、住所は、お使いの PC の上で動きます。データも手元に置きます。手元で読むので、クラウドベースの地図アプリより圧倒的に高速です。カテゴリのボタンも自分で選べます。必要な分だけ地図を読み、必要なときに地図のデータを更新できます。地図のサービスの規約が変わっても、急に有料になっても、今の地図は使い続けられます |
| ③ 日本ファースト。住所も駅も測量の座標も、そのまま使える | 住所（丁目・番・号）、駅の名前、平面直角座標、地域メッシュ、度分秒に、追加の設定なしで対応します |

約束の範囲（言い過ぎないための添え書き）：

- **①**：測った時間は、評価の3回目（50問）で、送ってから答えが届くまで中央値 5.25秒、50問中45問が 8.5秒以内、最長 13.1秒です（Claude を待つ時間を含む。`eval/runs/2026-11-05T13-51-03-359Z.json` の `ms`）。
- **①**：Mac のアプリは .dmg から入れます。署名がないので、初めて開くときは下の「[Mac のアプリ](#mac-のアプリ)」の開き方が要ります。地図のデータの用意は、初めて開いたときだけ約4分かかります（この Mac Studio で測った値）。
- **②**：Claude API がなくても動くのは、地図、カテゴリのボタン、拡大・縮小、現在地、貼った座標への移動、ルートのフォーム（名前・住所・座標・現在地・地図で選んだ点から、AI を通さずにルートを引く）、共有リンク、画像と GPX の書き出し（GPX はルートがあるときだけ）、レシピの再実行です。止まるのは日本語の新しい依頼です。寄り道先を「郵便局」のような言葉から選ぶルート、着く時刻からの逆算、試走コースには、Claude が要ります。
- **②**：使っているあいだに外に出る通信は Claude API だけです。地図のデータを取るとき（Mac のアプリを初めて開いたときと、「最新にする」を押したとき）だけ、download.geofabrik.de（OSM）、build.protomaps.com（地図）、github.com とその配信先（住所のデータと、ルートの速度表）に通信します。これらが止まっていると「最新にする」は失敗しますが、手元のデータはそのまま使えます。
- **②**：速さはこの Mac Studio で測った値です。カテゴリのボタン（郵便局 104件）は 26ms、名前の検索は数ms（2文字の名前の一部での検索は約0.2秒）、ルートは 0.3〜0.6秒、2回目からの起動は1秒以内です。前の構成（Docker の Overpass）では、名前の一部での検索に 8〜11.5秒かかっていました（検索の速さは 2026-11-07 に測った値）。クラウドの地図アプリと並べて測ったものではありません。
- **③**：住所はデジタル庁のアドレス・ベース・レジストリ（ABR）の住居表示で引きます。引ける位置は、ABR に点がある住所なら号の位置、なければ街区の代表点です。たとえば「港区芝公園4-2-8」は街区（芝公園4丁目2）の代表点になります。地番の地域（住居表示をしていない地域）は、町・丁目や市区町村の代表点になることがあります。どの場合も、精度（「座標の精度：街区の代表点」など）を画面に出します。
- **③**：平面直角座標を出すのは東京都（9系）です。読める座標の書き方は下の「[日本の座標](#日本の座標)」にあります。

## デモの流れ

デモ動画は、人が画面を操作して撮ったものではありません。本物のアプリと本物の Claude を Playwright で自動で動かして録りました。字幕の数字は、録ったときの操作の結果から作っています（`scripts/video/`、`docs/storyboard/`）。現在地は撮影用に品川駅 高輪口にしています。下の例1と「AI を通さないルート」の数字も、録画のときの操作の結果です（動画の字幕では 0.1秒の単位に丸めています）。

### 約束の場面で流す操作

1. **言葉から地図へ**：「芝公園のあたりを大きく。郵便局だけ残して」と頼むと、地図が動きます。
2. **カテゴリのボタン**：「郵便局」「手土産」のボタンを押すと、AI を通さずに地図に出ます。並びの最後の「編集」から、辞書の13語の中で足す・外す・並べ替えもできます（カスタマイズ。並びはこのブラウザに保存します）。
3. **AI を通さないルート**：地図の点をクリックし、地点のカードの「ここへ行く」を押します。出発を「現在地」にして、自転車で「ルートを検索」。録画では、押してから表示まで 0.56秒、自転車で 19.1分・5.51km でした。Claude は呼びません。
4. **日本ファースト**：検索の欄に平面直角座標を貼ると、AI を通さずにその場所へ動き、地点のカードに緯度経度、度分秒、平面直角座標（9系）、地域メッシュが出ます。

### 例1：用事を済ませてから、客先へ

想定：客先へ向かう営業担当。頼むのは、このひとことだけです。

> 今いる場所から、郵便局で契約書を出して、客先への手土産を買い、カフェで30分資料を確認してから、15時20分までに港区芝公園4-2-8の客先へ。ルートを共有リンクで

- Claude は、このひとことを3つの操作（住所の検索 → ルート → 共有リンク）に分けました。依頼から結果まで 6.6秒でした（Claude の処理時間を含む）。
- 寄る場所は、プログラムが27通りの組み合わせを計算し、いちばん早いものを選びました（泉岳寺駅前郵便局 → 文銭堂 → カフェ麻呂）。車で 7.5分・3.68km です（運転の時間。カフェの30分は含みません）。
- 行き先の「港区芝公園4-2-8」は、手元の住所のデータで「芝公園4丁目2」（街区）まで一致しました。号の「-8」は一致しないので、街区の代表点に向かいます。
- 寄り道で増える時間は 30.1分（運転 +0.1分、カフェ 30分）。15時20分に着くには、14時42分までに出発します（運転時間と滞在時間から逆算。渋滞は含みません）。
- 共有リンクを別のブラウザで開くと、同じルートと出典が出ます。

### 日本の住所と座標

- 「港区芝公園4-2-8」「港区芝公園四丁目2番8号」「港区芝公園４－２－８」「港区芝公園4丁目2-8」は、どれも同じ街区（芝公園4丁目2）として引けます（2026-11-07 に手元の住所のデータで試した結果）。
- 「品川駅」と頼んでも、OSM の駅の名前は「品川」です。ことづては、駅としても探します。
- 測量の座標（平面直角座標の19の系、地域メッシュ、度分秒）も、貼るだけで地図へ動きます。

### 開発は Claude Code で

- hook が、開発中から公開サービスを使うコードを止めます（ローカルファーストになるように）。
- 評価セットは、Claude が依頼を正しい操作に分けたかを、プログラムが採点する50問です（ふつうの頼み方40問と罠の10問）。評価セットは、プロンプトを直す前にコミットしました。結果は 78%、94%、100% です。AIが座標を作った回数は、どの回も0です。3回とも 11/5 に、着く時刻と移動の手段を足す前の版で測りました。
- MCP でも同じ操作を使えます。

詳しくは「[Claude Code の使い方](#claude-code-の使い方)」と「[評価](#評価)」にあります。

### 外部通信の記録とレシピ

- 結果の「詳細」を開くと、外部通信の記録が出ます。例1で外に出たのは、Claude への4件だけでした。ほかは手元で動きます。
- やった操作の並びは、レシピとして保存でき、Claude を使わずに再実行できます。そのときの Claude への通信は0件です。

Mac のアプリは .dmg から入れ、初めて開いたときに地図のデータを取って手元で作ります。メニューから最新にできます（下の「[Mac のアプリ](#mac-のアプリ)」）。

## 試す

Mac のアプリ（.dmg）を入れて試せます。入れ方は下の「[Mac のアプリ](#mac-のアプリ)」にあります。Web で試せる版はありません。日本語の依頼には、ご自分の Claude API のキーが要ります。

- 範囲は東京都（島しょ部を除く）です。たとえば「東京タワーの近くの郵便局」「今いる場所から、郵便局に寄って東京タワーへ。ルートを共有リンクで」「品川駅から皇居まで歩いて」と頼めます。検索の欄の横の「ルート」ボタンや、地図の点の「ここへ行く」からも、AI を通さずにルートを引けます。
- 出発地を書かない依頼は、現在地から引きます。現在地がないときは、画面にそう出ます。右下の現在地のボタンで位置情報を許可するか、地図で出発地をクリックしてください。
- 頼んだ文は Claude API に送ります。サーバは、呼んだ操作とその入力を手元のログに残します（現在地とクリックの座標は残しません）。共有リンクとレシピを作ると、その中身を手元に保存します。

## 何ができるか

| 操作 | できること |
|---|---|
| (a) 場所・住所 | 住所を ABR で調べ、座標の精度（住居番号の位置、街区の代表点など）をそのまま出す。施設や駅は OSM の名前で探す。「品川駅」のように「〜駅」で探して駅が見つかれば、駅だけを返す（OSM の駅の名前は「品川」）。「霞ヶ関駅」と「霞ケ関駅」のような、ヶ・ケ・が の書き分けも探し直す |
| (b) 地物の絞り込み | 郵便局、手土産、コンビニ、踏切、トンネルなど13語を、辞書で OSM のタグにして探す。どう解釈したかを毎回出す（例：「踏切＝railway=level_crossing（歩行者用の踏切（railway=crossing）は含まない）」） |
| (c) ルート・試走コース | 現在地から、郵便局やコンビニに寄って目的地へ。寄り道で増えた時間を出す。着く時刻を頼むと、寄り道先で過ごす時間も入れて、出発の時刻を逆算する（渋滞は含まない）。移動の手段は車・徒歩・自転車（「歩いて」「自転車で」と頼む）。電車・バスは時刻表のデータがないので引けず、そう出す（車に替えて引かない）。試走コース（例：トンネル2本、高速なし、60分以内。車だけ）は、経由地の候補をプログラムが作り、通った道の OSM のタグで「条件の確認」を作る。タグがなければ「分からない（データなし）」 |
| (c) AI を通さないルート | 検索の欄の横の「ルート」ボタンから、出発・経由地（最大3）・目的地、車／徒歩／自転車、車なら「高速を使わない」、入れ替え。欄には名前・住所・座標・現在地を入れるか、地図で選ぶ。地点のカードに「ここから出発」「ここへ行く」。Claude を呼ばない |
| (d) 資料用の地図・共有 | 共有リンク、出典とデータ時点を焼き込んだ画像、GPX・GeoJSON（社内確認用。ODbL の注意つき）、ピン |
| (e) 地図の表示 | 「芝公園のあたりを大きく。郵便局だけ残して」のように、移動・拡大・表示の切り替えも日本語で頼める |

このほか：

- **カテゴリのボタン**：検索の横のボタン（既定は郵便局・手土産・コンビニ・カフェ・駐車場・ガソリンスタンド・踏切・トンネルの8つ）は、AI を通さずに、手元の検索データから直接探します。右下のボタン（現在地・拡大・縮小）も AI を通りません。カテゴリのボタンは、並びの最後の「編集」から、辞書の13語の中で足す・外す・並べ替えができます（並びはこのブラウザに保存します）。
- **辞書にない言葉**：「近くのおいしいラーメン屋」のように辞書にない言葉は、そう出したうえで、地物で探せる言葉の一覧と「店や施設は、名前で頼むと探せます」を出します。
- **レシピ**：やった操作の並びを保存し、Claude を使わずに同じ順で再実行できます。
- **外部通信の記録**：操作のたびに、サーバが出した通信を「自社のサービス（地図・検索・ルート・住所）」「api.anthropic.com」「その他の外部」に分けて数えます。結果の「詳細」に出ます。
- **OSM ノートの下書き**：地図の誤りに気づいたら、OSM のノートの下書きを作ります。確認方法は本人が選び（「Googleマップで見た」は選べない）、会社を表す語や「試走」などが入っているとコピーできません。アプリは OSM と通信しません。投稿は現地を見た本人が手で行います。
- **MCP**：同じ操作を MCP のツールとしても使えます（下の「[MCP](#mcp)」）。
- **試走コース（デモの例2）**：想定は、条件つきのコースを作る人です。たとえば、品川駅を出て品川駅に戻る試走コース（トンネル2本、高速なし、60分以内）を作れます。動画からは外しましたが、アプリでは使えます。

### 日本の座標

- 地図をクリックした点と、地点の詳細（「座標」を開く）に、緯度経度、度分秒、平面直角座標（JGD2011。東京は9系）、3次の地域メッシュ（8桁）を出します。値は地図の位置から計算したもので、測量の値ではありません。
- 検索の欄に座標だけを貼ると、AI を通さずにその場所へ動きます。読める書き方：
  - 10進の緯度経度（`35.681236, 139.767125`。経度が先でもよい）
  - 度分秒（`北緯35°40′52.4″ 東経139°46′01.6″`、`35度40分52秒 139度46分2秒`）
  - 北緯・東経や N・E の付いた10進（`北緯35.681236 東経139.767125`、`N35.681236 E139.767125`）
  - 平面直角座標（`9系 X=-35363.24 Y=-5992.92`）。系はローマ数字（`第Ⅸ系`）でもよいです。
    - 東京では系を省けます。そのときは X=・Y= を付けるか、マイナスの付いた数で書きます。
    - X=・Y= がなければ、X（北）、Y（東）の順に読みます。どう読んだかは、地点のカードの題に出します。
  - 地域メッシュ（4桁・6桁・8桁。`5339-46-11` のようにハイフンがあってもよい。中心へ動く）
  - 全角の数字と記号、かな入力の「ー」も読みます。
  - 日本の外の緯度経度は、Claude に送らずに「日本の範囲の外の座標です」と出します。
- 計算は画面の中だけで行います（国土地理院の式。1〜19系。地域メッシュは JIS X 0410）。国土地理院の計算の値と 1mm 以内で合うことを `scripts/check-quick.ts` で確かめています。

## アプリの中での Claude の使い方

ことづての Claude は、答えの文を書きません。日本語の依頼を「地図の操作の並び」に訳します。Claude が選ぶのは、操作とその入力（辞書の言葉、場所の参照（`result:1`、`here:` など）、住所や施設名の文字、条件の数）です。座標、件数、分、◯/× は、手元のプログラムと地図のデータが出します。操作の並びはレシピとして保存でき、Claude を使わずに同じ順で再実行できます。検索を作り替えたときは、評価で Claude が選んだ並びを含む107件を Claude なしで回し、前の構成と結果が同じことを確かめました（`scripts/golden.ts`）。

| 決めたこと | 中身 | 場所 |
|---|---|---|
| モデル | `claude-sonnet-5-5`、effort は medium。ほかのモデルとは比べていません。評価の3回は、どれもこのモデルを指定して回しました | `src/server/claude.ts`、`eval/runs/` |
| 1つの定義から2つのツール | 操作は `src/ops` に zod の型で1回だけ書きます。同じ定義から、Claude の strict なツールと MCP のツールを作ります | `src/ops/registry.ts`、`src/mcp/server.ts` |
| 入力はサーバでも確かめる | 最小・最大や文字数は、strict なツールの定義から外して説明文に書きます。値はサーバが zod で確かめます | `src/ops/registry.ts` |
| 1回に1つの操作 | 1回の応答で使うツールは1つです（`disable_parallel_tool_use`）。前の操作の結果を見てから、次の操作を選びます。1つの依頼で Claude を呼ぶのは8回までです | `src/server/claude.ts` |
| アプリから Claude に座標を渡さない | 依頼ごとに渡す画面の状態は、参照（`here:`、`view:`、`result:N` など）、名前、件数、現在地の精度などで、座標は入れません。操作の結果も、操作ごとに Claude に返す形（`llm`）を決めていて、座標は入れません。依頼の文はそのまま渡すので、文の中に座標を書けば Claude に届きます（座標だけを検索の欄に貼ったときは、Claude に送らずに地図が動きます） | `src/server/claude.ts` の `contextBlock`、`src/ops/*.ts` の `llm` |
| プロンプトのキャッシュ | SYSTEM プロンプトとツールの定義をキャッシュします。評価の3回目では、入力のトークンの約94%（約96万）をキャッシュから読みました | `src/server/claude.ts`、`eval/runs/2026-11-05T13-51-03-359Z.json` |
| Claude を通らない道 | カテゴリのボタン、地図のボタン、ルートのフォーム、検索の欄に貼った座標だけの文、保存したレシピの再実行は、Claude を通りません。Claude API が止まっても、これらは使えます | `src/server/recipe.ts` ほか |

画面の決まり：

- Claude がするのは、依頼の言葉を読んで、操作（ツール）と入力を選ぶことです。入力は「Claude の解釈」の行に出します。
- 結果の値（見つかった名前、件数、かかった分、◯/×）は、地図のデータ（OSM、ABR）とツールの結果から来ます。画面の文章は、ツールの入力と結果からテンプレートで作ります。Claude の自由な文章は画面に出しません。
- 0件は「OSM上で0件（現地にないとは限らない）」、タグがなければ「分からない（データなし）」とそのまま出します。

AI に任せないこと：

- 場所は参照（`abr:N`、`result:N`、`osm:way/…`、`click:N`、`here:`）だけで指します。AI が書いた緯度経度は受け付けません。
- 検索の条件は AI に書かせません。辞書から選んだタグと範囲で、プログラムが組み立てます。範囲の面積、件数、時間に上限があります。
- 貼った座標は Claude に渡さず、画面の中で読みます。
- 操作の入力は、サーバが型（zod）で検証します。

## 評価

日本語の依頼を本物の Claude に渡し、選んだ操作と結果をプログラムで採点します（`eval/README.md`）。

設計の決まりと、測った結果を分けて書きます。

- **設計の決まり**：画面の文章は、ツールの入力と結果からテンプレートで作ります。Claude の自由な文章は出しません（上の「画面の決まり」）。これは作り方の決まりで、評価で測った数字ではありません。
- **測った結果**：自作の50問で 78% → 94% → 100% でした（下の表）。

評価セットについて：

- 50問：(a)〜(d) 各10問（(e) 表示の操作は (d) に入れる）と、罠10問（東京都の外、存在しない施設、辞書にない言葉、座標の指定、0件）。
- 問いの例（`eval/set.jsonl` から）：
  - ふつうの頼み方：「この画面に出ている範囲の郵便局を全部見せてください」「このルートを共有リンクにして」
  - 罠（引っかからずに答えられるか）：「横浜駅を地図に出して」（東京都の外）、「汐留ひかり公会堂ってどこ？」（ない施設）、「この辺に本屋ある？」（辞書にない言葉）、「北緯35.6812、東経139.7671に地図を動かして」（座標の指定）、「この画面の踏切を出して」（OSM上で0件）
- 正解の座標は、ABR の結果を使わずに OSM の要素など別のデータで決めています。
- **評価セットは自分たちで作ったものです。** 100% はこの50問での結果で、ほかの依頼でも同じとは言えません。
- 評価セットは、プロンプトを調整する前にコミットしました（cafb4a3）。調整は ceafe28 です。
- 3回とも 11/5 に、前の構成（Docker の Overpass、Valhalla、abr-geocoder）で測りました。
- そのあと、検索の「〜駅」と ヶ・ケ・が の扱いを直しました（11/7）。11/8 には、ルートの操作に着く時刻・寄り道先で過ごす時間・移動の手段の入力を足し、「出発地のないルートは現在地で呼ぶ」の1行をプロンプトに足しました（Claude に渡すツールの定義とプロンプトが変わります）。

- 現在地がないときの依頼を扱う問いは、評価セットにありません。この場合は画面の確認（`scripts/check-web.mjs`）で確かめています。

「AIが座標を作った回数」は、成功した操作の入力に座標らしい数字（`\d{2,3}\.\d{3,}`）があった回数です。採点のスクリプトは、依頼文にない言葉を「辞書にない言葉」として出した回数も同じ数に足します。ただしサーバが依頼文にない言葉を落としてから操作に渡すので（`src/server/claude.ts` の `quoted`）、こちらは作りの上で0回にしかなりません。2回目と3回目の間に、落ちた3問だけで調整を試しました（3/3）。結果のファイルは `eval/runs/` にあります。

```bash
npx tsx scripts/eval.ts
```

`.env` のキーが要ります。検索は地域の設定（`data/region.json`）があれば手元の SQLite、なければ Overpass :12345 を使います。ルートは Valhalla :8002（`VALHALLA_MODE=embedded` と `VALHALLA_CONFIG` で組み込み）、住所は `ABR_URL`（既定は :3002）です。1回で Claude を約140回呼び、約 $0.4、約5分かかります。`--only a01,b03` や `--group trap` で一部だけ回せます。

## ハッカソンのあと

目指すのは、業務で Google マップなどの地図アプリを使っていた人が、ことづてを使うようになることです。そのために、次の3つを満たす地図にします。

- 外部に依存しない。
- 日本語（自然言語）で操作できる。
- より使いやすい。

使い続ける場面（想定）：

- **出かける前に**：寄り道つきのルートと出発の時刻を作り、共有リンクで相手に送る。
- **チームで**：社内の共有サーバに1つ置く。毎週同じ操作は、レシピで Claude を使わずに再実行する。
- **資料に**：出典とデータ時点の入った画像を、報告書に貼る。
- **ほかの道具から**：MCP で、住所の一覧をまとめて地図にする（例：23区の区役所23件）。

続けて使うための仕組みは、期間中に作りました。

- **入れる**：Mac のアプリ（.dmg）は、コマンドなしで入れられます（下の「Mac のアプリ」）。
- **データを新しくする**：メニューの「地図のデータ…」→「最新にする」で、地図のデータを取り直して作ります。作るあいだは前のデータで使えます。失敗したら前のデータのままです。
- **Claude なしで繰り返す**：レシピに保存した操作の並びは、Claude を使わずに再実行できます。地図、カテゴリのボタン、AI を通さないルート、共有リンク、画像の書き出しも、Claude API なしで動きます。
- **チームで使う**：共有のサーバで動かせます。前にリバースプロキシを置き、そのホスト名を `ALLOWED_HOSTS` に書きます（下の「どこで動かすか」）。
- **ほかの道具から使う**：同じ操作を MCP のツールとしても使えます（`docs/mcp.md`）。

「外部に依存しない」の範囲：

- 使っているあいだに外に出る通信は Claude API だけです。日本語の新しい依頼には Claude が要ります。
- 「最新にする」を押したときだけ、Geofabrik、Protomaps、GitHub に通信します。これらが止まっていても、手元のデータは使い続けられます。

まだできていないこと：

- 地域は東京都（島しょ部を除く）だけです。1つのコマンド（開発する人向け）では他の地域も選べますが、確かめたのは東京だけです。
- Mac のアプリは Apple Silicon だけです。Windows 版は、このあとに作ります。

## Mac のアプリ

コマンドを使わずに入れられる Mac のアプリ（.dmg）があります。

- **対応**：Apple Silicon の Mac だけです。確かめたのは、この Mac Studio（M5 Ultra、96GB、macOS 27.0.1）だけです。
- **入れ方**：[GitHub Releases の v0.1.0](https://github.com/koji117/kotozute/releases/tag/v0.1.0) から .dmg（約216MB）を取り、開いて、ことづてをアプリケーションに入れます。
- **署名**：Apple の Developer ID の署名も公証もありません（ad-hoc の署名だけ）。ダウンロードしたものを初めて開くと、macOS が止めます。「システム設定 → プライバシーとセキュリティ」の下に出る「このまま開く」を押すと開けます。
- **初めて開いたとき**：
  1. Claude API のキーの画面が出ます。キーはキーチェーン（safeStorage）で暗号化して保存します。キーなしでも、地図、カテゴリのボタン、地図のボタン、AI を通さないルートは使えます。
  2. 「地図のデータ」の画面が出ます。地図のデータはアプリに入っていません。アプリが取って、手元で作ります。取るのは約0.7GB（OSM の関東 約500MB を Geofabrik から、地図 約190MB を Protomaps から、住所のデータ 約22MB を GitHub から）です。
  3. この Mac では、押してから地図が出るまで約4分（252秒）でした。そのうち OSM のダウンロードが153秒（約3.4MB/s。回線の速さによる）、作るのが約100秒です。作ったあとに残るのは約1.5GB です。作るあいだは最大約4.2GB を使うので、ディスクの空きが約5GB 要ります。作るときのメモリは最大約3.8GB です。
- **2回目から**：約1秒で地図が出ます。
- **使っているときのメモリ**：アプリの全部のプロセスの合計で、地図を出したとき約0.8GB、ルートを引いたあと約1.3GB でした。
- **地図のデータを新しくする**：メニューの「地図のデータ…」→「最新にする」。作るあいだは前のデータで使えます。できたら切り替えます。失敗したら前のデータのままです。
- **データの置き場所**：`~/Library/Application Support/kotozute/`（共有リンク、レシピ、操作の記録、キー、地図のデータ）。
- **OSM ノートで止める語**（社名など）：メニューの「OSM ノートで止める語…」で開くファイル（`note-block-words.txt`）に、1行に1語で書きます。書いたらアプリを開き直します。`npm start` では `.env` の `NOTE_BLOCK_WORDS`（カンマ区切り）に書きます。
- 地域は東京都だけです。

## 1つのコマンドで動かす（開発する人向け）

Node 24 以上が要ります。リポジトリの直下で：

```bash
npm install
```

```bash
npm run setup -- --region=tokyo
```

```bash
npm start
```

ブラウザで http://localhost:8787 を開きます。日本語の依頼を使うときは、`.env` に `ANTHROPIC_API_KEY` を書きます。

- 地域は `tokyo`、`japan`、Geofabrik の日本の8地方、47都道府県から選べます。確かめたのは東京だけです。
- `npm run setup` は、OSM の pbf を TypeScript で読んで検索データ（SQLite）を作り、ルートのデータ（Valhalla のタイル）、地図の切り出し、住所のデータ（abrg の DuckDB）を作ります。住所の道具（abrg）は Go でビルドするので、Go と C のコンパイラが要ります（Mac は `xcode-select --install`）。住所のデータを一から作るときだけ Docker を使います。osmium は、東京以外の境界を作るときだけ使います。
- `npm run setup` が取りに行く先は、設計書（`docs/superpowers/specs/2026-11-06-one-command-setup-design.md` の §3）にあります。実行時に外に出るのは Claude API だけです。
- 確かめ方（`scripts/check-*.ts`、`scripts/check-web.mjs`）は `docs/HANDOFF.md` にあります。

### どこで動かすか

- **1人で使う**：自分の機械で動かし、http://localhost:8787 を開きます。
- **チームで使う**：共有のサーバで動かします。アプリのサーバは 127.0.0.1 だけで待ち受けるので、前にリバースプロキシを置きます。そのホスト名を環境変数 `ALLOWED_HOSTS`（カンマ区切り）に書きます。書いていないホスト名からの API は断ります（403）。ブラウザの位置情報（現在地）は HTTPS か localhost でないと使えないので、プロキシは HTTPS にします。
- 共有リンクを開けるのは、そのサーバに届く人だけです。届かない人に渡すものは画像です。

```

   ├─ 日本語の依頼 → Claude API（ツールを選ぶ）※ 外に出るのはここだけ
   │                                      ▼
   │                  操作の一覧（src/ops、zod で検証、操作ログ）

   │                           ├─ ルート：Valhalla を同じプロセスで（@valhallajs/valhallajs）
```

- 日本語の依頼に使うモデルは `claude-sonnet-5-5`（`src/server/claude.ts`）。キーはサーバの環境変数 `ANTHROPIC_API_KEY`（`npm start` は `.env` から、Mac のアプリはキーチェーンから）で渡し、ブラウザには置きません。
